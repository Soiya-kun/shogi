# 援軍の待機配置

各陣営から見た戦場の右手前に、持ち駒の待機部隊を表示する。9×9の合法手マスには置かず、草原内の外周（先手はX・Zが正、後手は反対側）に配置する。

- 同じ兵種を一つにまとめ、通常サイズの代表兵2人と「歩 ×3」などの旗で表す。数値は人数ではなく、投入できる部隊数。
- 足軽・重装武者・弓兵と騎馬隊長・陰陽師と護衛・騎馬を兵種に応じて表示。兵士や馬自体は縮小しない。最大7兵種×2人×両陣営＝28人で、持ち駒数が増えても場所を増やさない。
- 捕獲時に最新の持ち駒数を反映し、打つと減らす。戻す・復元・リセットでも対局状態に同期。成駒は元の兵種へ戻す。
- 手番側の旗を左クリックすると援軍を選択できる。右側の持ち駒ボタンも利用できる。AI操作中・相手の待機部隊は操作できない。
- 駒名ON/OFFは待機部隊にも適用する。対局マスの部隊や戦闘残像と別に描画し、待機部隊を盤上の駒として判定しない。
