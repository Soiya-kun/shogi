# 黒金一番街 v3 のWeb反映

2026-09-06。保存済み `assets/blender/yankee/crossroads-v3/yankee-neon-district-v3.blend` を `scripts/export_yankee_v3.py` で書き出す。制作原本は保存・上書きしない。人物8種は配信中のGLBとSHA-256が全て一致しており、今回の更新対象は街。

赤い電飾ゲート、奥へ続く雑居ビルと看板、排水溝、舗装補修、電線、室外機、店先の小物を反映する。舞台名を「黒金一番街 / Kurogane Night District」へ更新。舞台ID・対局保存・3mマス・27m盤・40人の構成は維持する。

## Webへの変換

- 制作確認用の40人物インスタンス、確認グリッド、カメラ、ライト、非表示オブジェクトを除外。ゲームの局面から40人を配置する。
- 静的な街を材質単位にまとめる。細い曲線の分割数、密度の高い形状を軽量化し、文字の輪郭は残す。
- Blenderのワールド座標による写真テクスチャ投影を面方向のUVへ変換。写真の色・粗さと発光看板をGLBへ内包する。写真は1024pxへ縮小し、色画像はJPEGで保存する。
- CC0素材の出典を配信用 `texture-sources.json` に保持する。ユーザー提供の街の参照写真はテクスチャに使用しない。
- Blenderのノイズ合成、投影の面間ブレンド、微細バンプ、Cyclesの反射・間接光はそのまま再現しない。Webでは写真材質と形状の汚れ、看板の自己発光で表現する。
- 従来の均一な仮地面を描画しないよう変更し、元モデルの舗装を見せる。操作判定用の水平面は保持する。夜景用に環境光と主光源を調整する。

原本の更新後は再書き出しし、`dist/assets/stages/yankee/manifest.json` の容量・ハッシュも更新する。
