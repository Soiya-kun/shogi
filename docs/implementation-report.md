# 草原フィールド・Blenderモデルの実装記録

実施日：2026-09-05

## 結果

盤状の石造りフィールドを、Blender製の草原・丘に置き換えました。地面に沿う9×9の線と、8兵種・40体の兵士を表示し、従来の将棋操作を維持しています。編集用`.blend`、配信用GLB、再生成・再書き出しスクリプトを含みます。

| 項目 | 実施内容 |
| --- | --- |
| フィールド | 緩やかな丘、小道、草花、木、岩、周辺のアーチと陣営旗 |
| マス目 | 地形GLBの三角形を参照し、線・選択・移動先を地面の直上へ配置 |
| 兵士 | 歩兵、槍兵、騎兵、剣士、近衛兵、魔導士、重装騎士、ロード |
| 装備 | 鎧・兜・武器・盾・マント・馬。陣営色と成り後の金装飾 |
| 演出 | 待機、手足を動かす移動、攻撃、捕獲対象の退場、持ち駒投入、昇格の光 |
| 操作 | マウス・タッチ・矢印＋Enter。視点回転・俯瞰・駒名切替 |
| 保存 | 既存のlocalStorageキーを維持し、保存データの構造を検証して復元 |
| MCP | 直接ツールで接続し、生成したBlenderファイルを開いて操作確認 |

## 検証

次のコマンドが成功しています。

```sh
npm test
npm run build
npm run test:web
```

- Nodeテスト5件：既存のルール検証、合法手以外の拒否、保存復元、一手戻す、千日手、81マスの座標往復、地形の傾き・穴の検証。
- ブラウザテスト4件：40体表示、クリック移動、キーボード、保存復元、一手戻す、視点、成り、捕獲、持ち駒投入、390px幅のタッチ操作、GLB取得失敗時の再読込表示。
- 兵士が奥の移動先を覆ってクリックを吸う不具合を検出し、合法な移動先の地面を優先して選ぶよう修正。該当する成り操作のテストが成功。
- Blender編集用ファイルから`export_assets.py`で再書き出しし、生成用スクリプトに頼らず配信GLBを更新できることを確認。
