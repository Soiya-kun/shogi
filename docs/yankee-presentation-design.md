## 1. 表現の方向

**雨上がりの交差点で、総長と仲間たちが張り合う抗争劇。** 軸は「カチコミ」「気合」「仲間への義理」「下剋上」。全員を怒鳴らせるより、若手の勢い、副総長の落ち着き、総長の短い一言で差を出す。

「夜露死苦」はAIへの指示を受ける場面などに絞る。当て字だらけにせず、タイトルは一目で分かる日本語、台詞は短く自然にする。武将の「我ら」「本陣」「兵を進めよ」は、ヤンキーでは「俺たち」「総長」「行くぞ」に置き換える。

駒は1マス1人。捕獲は相手が膝をつく・引くことで決着し、死亡ではない。持ち駒はゲーム上の再登場待ちとして扱う。捕獲だけで「忠誠を誓った」「裏切った」といった内面は断定しない。

### 表示例

```text
カチコミ                     王手
RAID                         CHECK
先手                         後手
カチコミだ。気合入れろ！      オラ、総長。出てこいや！
```

タイトルは英語設定でも日本語を主役とする。英語副題は既存設定で表示／非表示。説明・台詞は選択した言語だけを表示する。王手・詰み、棋譜、移動可能範囲などのルール表記は維持する。

### 台詞を書く規則

- 短い呼びかけ→啖呵の順を基本にする。「オラ、行くぞ」「上等だ。やり返すぞ」「ナメてんじゃねえぞ」のように、語尾だけでなく態度を作る。これらの台詞は本作の創作例。
- 表記は「ねえ／じゃねえ」「てめえ」「おめえ」「ナメる」に揃える。すべての文に「コラ」「オラ」を足さず、強い呼びかけは一つまで。
- 敵への「てめえ」と仲間への「おめえ」、上役への「総長」「〜っス」を分ける。プレイヤーの設定操作へ敵向けの罵声を出さない。
- 基調は標準語を崩した口調とする。「なんやワレ」「〜じゃけえ」などを同一人物へ無造作に混ぜない。地域別キャラクターを作るなら別の話法設計を行う。
- 若手は威勢と背伸び、長ランは押しの強さ、武闘派は短い威圧、副総長は筋と仲間、切れ者は皮肉、バイク勢は勢い、総長は少ない言葉で締める。
- 当て字には読みデータを用意する。「本気」の音声は「マジ」。字幕の初出には本気（マジ）と補える構成にする。英訳は単語の直訳ではなく、その場の挑発・励まし・信頼を訳す。
- 素材未作成時は下表の一つの既定台詞を使用する。本人ボイスを追加するときだけ話者ごとの文案へ切り替え、若手本人の台詞を総長の声で喋らせない。

## 4. 文字・画面・音

### 画面の見せ方

- 左下の既存演出帯に表示し、5秒で消す。AI開始95も左下。96／97は既存の指揮カード内の返答を基本とし、パネルが閉じている場合は左下へ表示する案とする。同じイベントを両方へ出さない。
- 墨と巻物の代わりに、黒いステッカー風の下地、白い荒めの太文字、朱／青の細い縁。陣営色は既存の先手青・後手赤を維持し、先後の文字も残す。
- カチコミ：文字が横から短く滑り、侵入した駒の足元に一度だけ円弧。敷地全体を赤く塗ったり、占領ルールを連想させる領域は残さない。
- 助太刀：対象の着地点に短い街灯色の輪。歩行者は一歩踏み出す。バイクは短い制動姿勢。場外から盤上を横断する長い移動は作らない。
- 本気（マジ）：一拍の白い縁光と背中の紋。飛車が成っても架空の龍や炎は出さない。モデル差分が未完成なら姿勢と駒名だけで成立させる。
- 王手：相手総長の足元を短く示す。詰み：重い一押しの文字。決着：勝者名とともに街灯の暖色を局所的に添える。
- カメラの強制移動、全画面の揺れ、ホワイトアウトは標準で使わない。駒名、合法手、ドラッグ・ズームを妨げず、演出はクリック透過にする。
- 控えめ／OSの低動作設定は静止帯と字幕のみ。OFFでも通常UIの王手と終局理由は表示する。

### 音と声

総長の低く短い声を基本に、最初は1話者で揃える。将来の本人ボイスでは若手は勢い、武闘派は短い息、副総長は静かな断言、切れ者は余裕、バイク勢は軽快さで分ける。先後で善悪や性格を固定しない。

| 場面 | 音の案 |
| --- | --- |
| カチコミ／喧嘩上等 | 靴の踏み込み＋短い低音。バイクが対象なら短いエンジン音 |
| 助太刀 | 一歩の靴音、または短いブレーキ音 |
| 本気（マジ） | 一度のアクセント＋短いエンジンの吹き上がり |
| 王手 | 乾いた一打。連続王手でも声は頻度制限 |
| 詰み／決着 | 決着の一打、その後に短い余韻。終局BGM案は別途 |

台詞は約1〜2秒。音声は既存設定の既定OFFを維持する。未収録でも字幕を出し、他舞台の武将音声で埋めない。複数戦闘の効果音は同時数と音量を制限し、掛け声は共通の単一再生・8秒／同陣営4手間隔を守る。

## 5. 駒取りモーションの方向

**戦闘区間は1.5秒。** 既存の接近600ms＋戦闘1,500ms＋占有600msを維持する。攻撃側が勝つ結果は合法手の確定時に決まっており、モーションで勝敗を抽選しない。1.5秒の中で「相手も応戦した」と分かる一往復を入れる。

| 駒・役 | 攻撃側の特徴 |
| --- | --- |
| 歩・若手 | 踏み込み、短い連打、最後に気合を入れた一打 |
| 香・長ラン | 直線的な踏み込み、肩で押し込む。長ランの裾が追従 |
| 桂・旧車乗り | 小さく車体を傾けて進入、停車して上体の一撃。人へ車体をめり込ませない |
| 銀・武闘派 | 重いガード、相手の一打を受けて大きく押し返す |
| 金・副総長 | コンパクトに受け、最短の反撃。派手さより安定感 |
| 角・切れ者 | 半身でかわし、一歩ずらして反撃。将棋の移動先自体は変えない |
| 飛・特攻隊長 | 制動して対峙、上体の反撃と短いエンジンの煽り |
| 玉・総長 | ほぼ動じず受け、短い一撃で相手を退かせる |

戦闘内の目安は0〜300msで構え、300〜950msで攻防一往復、950〜1,500msで決めと敗者の退場。敗者は仮表示として引き下がり、持ち駒の論理状態へ影響しない。攻撃側の姿勢と防御側の反応を組み合わせ、兵種ペアごとの64本の専用アニメーションを前提にしない。

成駒はまず同じ人物・同じ車体で、構えと紋章の差分を使う。成り衣装は別の美術工程。駒名ラベルの成り表記を必ず残す。実在の俳優・作品の決め台詞や既存映像の流用は前提にしない。

## 6. 共通基盤への接続方針

1. `battle-events.mjs` の検出結果は共通ID・駒ID・陣営・局面revision・根拠を保持する。テーマ固有の文言を検出条件へ混ぜない。
2. 新設する表現カタログを `theme + eventId` で解決する。提案ファイル名は `presentation-themes.mjs`。データには主題、英語副題、日英台詞、視覚キュー、音声キーを持たせる。
3. 表示・ログ・音声が同じ解決結果を使う。IDや頻度制限キーは変えず、名前の変更で同じイベントを二重に再生しない。共通カタログは生成物なので直接上書きせず、既存のカタログ生成経路を維持する。
4. ヤンキーの対応漏れは「王手」等の中立な共通名＋台詞なし＋音声なしとする。武将の台詞を漏らさない。未実装イベントに表現データがあっても検出を有効化しない。
5. 音声は舞台／イベント／言語を区別し、必要なら陣営・話者を追加する。欠損・404・再生拒否では字幕だけを完走する。遅れて読めた音声が取消後に鳴らないよう再生世代を確認する。
6. テーマは対局開始時に固定。舞台切替、戻す、リセット、AI停止で古い字幕・音声・予約・解析結果を破棄する。保存復元で過去の演出を再生しない。

AIは標準3秒に1手を維持し、字幕5秒／戦闘1.5秒／音声の終了を待たない。新しい着手は表示済み字幕を残り5秒まで維持できるが、新しい主演出があれば置換する。優先順位・一着手最大1主表示・29→30の順次表示を引き継ぐ。

同じ人物の再移動、取り返し、捕獲直後の打ちは既存の表示世代による競合処理を維持する。音や姿勢も古い人物インスタンスではなく当該表示世代に結び付ける。舞台切替／戻す／リセット時には3D側も再構築し、AI停止だけなら既に確定した別駒の戦闘は完走できる。
