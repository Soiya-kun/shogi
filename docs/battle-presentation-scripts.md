# 戦局演出・大将の掛け声：スクリプトと発動条件100案

作成日：2026-09-06

状態：共通基盤と44案を実装。対応範囲・制約・検証結果は [戦局演出の実装状況](battle-presentation-status.md) を参照。未対応の案は発動しない。音声は未収録。

拡張：初稿01〜30を保持し、手筋・部隊の活躍・戦局・戦歴・大将の反応を31〜100として追加。

## 1. 狙い

戦法が形になった瞬間、読みが決まった瞬間、危機をしのいだ瞬間を、力強い漢字と大将の声で印象づける。海外のプレイヤーにも、漢字を読めなくても「何が起きたか」「どちらの軍が活躍したか」が伝わることを目指す。

基本形は **漢字の一撃 → 対象部隊の反応 → 大将の短い掛け声**。日本語音声を主役にし、短い英語の見出しと字幕を添える。将棋用語と演出用の呼び名は区別し、演出による能力上昇や追加ルールは作らない。

例：大筆の「両取り」が走る → 攻撃元と二つの対象に短い光 → 「二つに一つだ。選んでみよ！」。英語は `FORK` と `Two targets. Make your choice!`。

関連：[AI・戦法・作戦指示の設計方針](ai-strategy-design.md)。先手・後手の両方、手動操作・AI操作の両方に同じ判定を使う。

**非同期の必須要件（2026-09-06合意）**：移動・戦闘・筆文字・掛け声の完了を、次の思考・着手の条件にしない。AI同士の対局では、戦闘の再生中にも次々と指し手を進め、別部隊の移動・戦闘を並行再生する。確定済みの戦闘は新しい着手だけを理由に一律破棄せず、同じ部隊の再移動・取り返し等の競合時に短縮・中断する。兵種ごとの採用演出と詳細は[駒取り・部隊戦闘アニメーションの設計方針](capture-animation-design.md)を参照。

## 2. 共通の発動ルール

### 判定のタイミング

1. 合法な着手を確定し、着手前後の局面・持ち駒・棋譜を保存する。
2. 局面の変化から候補イベントを抽出する。「既にそうなっている」だけでは再発動しない。
3. 読みが必要な候補は、対応する局面の解析結果が得られた場合だけ採用する。
4. 同じ着手の候補を優先順位でまとめ、移動演出の着地・到着に合わせて表示する。
5. 新しい着手、戻す、リセット、復元で不要になった予約・解析結果を破棄する。

戦法や作戦の選択ボタンだけでは「発動」としない。指示を受け付けたときの小さな返答と、盤面上で作戦を実行したときの決め演出を分ける。

### 条件で使う判定

| 記号 | 意味・実装上の注意 |
| --- | --- |
| 確定判定 | 合法手、成り、持ち駒、王手、駒配置、終局などから直接判定できる。 |
| 形判定 | 登録した配置テンプレートとの一致。名称に必要な駒まで確認し、一部だけで成立扱いにしない。 |
| 解析判定 | エンジン評価や読み筋を利用する。上限・下限だけの値、未完了探索、異なる比較条件を混ぜない。 |
| 証明判定 | 対象の合法応手を全て調べる必要がある条件。探索が打ち切られた場合は未成立として扱う。 |
| 良手ゲート | 同じ開始局面・同じ完了深さで、その着手の評価が最良候補から100cp以内という暫定条件。結果がないときは「妙手」「見事」などの断定を避ける。 |
| 安全ゲート | 良手ゲートに加え、当該着手が確認済みの負け詰みに入らない。有限探索なので、絶対に安全という意味ではない。 |
| 玉周辺 | 玉から縦・横・斜めに2マス以内。攻撃数だけでなく、守備駒・遮蔽物・ピン・合法性を考慮する。 |
| 評価値 `E(s)` | 常に陣営sにとって良いほど大きい値へ統一する。詰み評価はcpに換算しない。 |
| 発動キー | `gameId + positionRevision + eventId + side + 対象駒ID`。同じ盤面へ戻った場合も、古い非同期結果と区別する。 |

100cp等はエンジン固定後の調整用数値であり、棋力や勝率の保証ではない。形・詰み・勝敗を含め、駒の人数や地形の高低は条件に使わない。

### 先後対称・駒の追跡

- 配置判定は対象陣営を先手向きへ180度回転して正規化する。後手にも同じテンプレートを適用する。
- 盤上の駒を追跡する安定IDを演出用に持つ。移動でIDを変えず、捕獲・再投入は所有者と状態を更新する。
- 「前進」「敵陣」「自陣」は陣営基準。「飛車」は昇格前、「竜」は昇格後を区別する。
- 初期配置、保存復元、巻き戻しで条件が成立していても、決め演出は再生しない。リプレイ時の再生は別設定にする。

### 尺・同時発動・頻度

| 区分 | 漢字・画面演出 | 音声 | 用途 |
| --- | --- | --- | --- |
| 小 | 0.6〜0.9秒、盤面の端 | 原則なし、または一言 | 王手、通常の援軍、通常の成り |
| 中 | 1.0〜1.4秒、画面中央寄りの帯 | 約1〜2秒 | 戦法成立、両取り、危機対応 |
| 大 | 1.5〜2.0秒、幅広い筆文字 | 約2秒 | 逆転、証明済みの必至、詰み、勝利 |

- 決め文字は一着手につき最大1件、掛け声も最大1件。副イベントは小さな戦況ログにまとめる。
- 優先順位は「終局 ＞ 証明された詰み・必至 ＞ 王手への対応・危機 ＞ 好手 ＞ 戦法成立 ＞ 通常動作」。同順位は具体的な条件を持つ演出を優先する。
- 汎用掛け声は全体で最低8秒間隔、陣営ごとに最低4手間隔。同種の中演出は原則として陣営ごとに12手空ける。終局は例外。
- 王手等のルール表示は毎回正しく出すが、大声は連続させない。以下の個別制限がより厳しい場合はそちらを優先する。
- カメラの強制移動・長いスローモーションを標準にしない。ユーザーのドラッグ・ズームを妨げず、文字をクリック透過にする。

## 3. 戦法・作戦が形になる演出：01〜08

### 01｜居飛車 — STATIC ROOK

- **発動条件【形＋解析】**：対象側の初期配置由来の飛車が2筋にあり、2筋の歩が初期位置から2段前進済み、角道を開ける7筋の歩が前進済み。自分の着手で三条件が初めて揃い、安全ゲートを通る。初期配置の飛車位置だけでは発動しない。
- **漢字・演出**：「居飛車」を横一閃。飛車部隊から2筋へ細い墨線を走らせ、槍隊が前へ構える。中演出。
- **大将**：「正面を押し開け！ この筋を制するぞ！」
- **英語字幕**：`Break through the front! This file is ours!`
- **制限**：各陣営1局1回。「居飛車全般の厳密な認定」ではなく、本アプリの居飛車布陣完成パターンとして扱う。

### 02｜四間飛車 — FOURTH-FILE ROOK

- **発動条件【形＋解析】**：初期配置由来の飛車が6八、6筋の歩が6六以遠へ前進、7筋の歩が前進済み。飛車の横移動または歩の前進で初めて成立し、安全ゲートを通る。
- **漢字・演出**：「四間飛車」の筆を横へ振り抜く。飛車の移動経路に一度だけ風が走り、幟が同方向へなびく。中演出。
- **大将**：「陣を振れ！ 横から戦を動かすぞ！」
- **英語字幕**：`Shift the formation! Turn the battle from the flank!`
- **制限**：各陣営1局1回。敵の飛車を捕らえて同じ場所へ打つだけでは成立しない。

### 03｜中飛車 — CENTRAL ROOK

- **発動条件【形＋解析】**：初期配置由来の飛車が5八、5筋の歩が5六以遠へ前進。対象側の着手で初めて成立し、安全ゲートを通る。
- **漢字・演出**：「中飛車」を縦に叩き込む。5筋に低い風圧、中央の部隊が一斉に武器を上げる。中演出。
- **大将**：「中央を貫け！ 道は我らが作る！」
- **英語字幕**：`Pierce the center! We make our own path!`
- **制限**：各陣営1局1回。王手回避の一時的な飛車移動だけでは発動しない。

### 04｜美濃囲い — MINO FORTRESS

- **発動条件【形】**：正規化した配置で玉2八・銀3八・金4九・金5八を満たす基本テンプレートが、自分の着手で初めて完成する。自玉が王手でない。高美濃・銀冠は別テンプレートができるまで本判定に混ぜない。
- **漢字・演出**：「美濃囲い」。玉と守備駒の間に弧を描き、墨の城壁が一瞬だけ立つ。中演出。
- **大将**：「陣は整った。ここを足場に打って出る！」
- **英語字幕**：`Our fortress stands. From here, we strike!`
- **制限**：各陣営1局1回。「難攻不落」とは称さない。危機演出と重なるときはログだけにする。

### 05｜穴熊 — BEAR-IN-THE-HOLE

- **発動条件【形】**：まず正規化した居飛車穴熊の1形、玉9九・香9八・桂8九・銀8八・金7八・金7九の全配置を登録する。自分の着手で初めて一致し、自玉が王手でない。振り飛車穴熊等は検証済みテンプレートを追加してから対応する。
- **漢字・演出**：「穴熊」の重い落款。画面端の本陣に土煙と低い太鼓を一発。中演出。
- **大将**：「本陣を固めよ。攻め手は存分に働け！」
- **英語字幕**：`Secure the stronghold. Let our attackers advance!`
- **制限**：各陣営1局1回。玉が隅にいるだけでは成立しない。

### 06｜攻勢 — PRESS THE ATTACK

- **発動条件【作戦＋解析】**：作戦「攻勢」の有効化後、自分の確定着手で敵玉周辺への有効な攻撃元が2部隊以上となり、着手前より増加。安全ゲートを通る最初の手。
- **漢字・演出**：「攻勢」。朱の筆跡が敵陣へ伸び、攻撃参加部隊の武器がきらめく。中演出。
- **大将**：「今だ、行けぇ！ 一気に押し込め！」
- **英語字幕**：`Now! Advance! Drive them back!`
- **制限**：指示のON/OFF連打では再発動しない。同一の攻勢局面では1回。相手に渡す次の一手を示す矢印は出さない。

### 07｜守勢 — HOLD THE LINE

- **発動条件【作戦＋解析】**：作戦「守備」の有効化後、玉の安全性を改善する手を確定し、安全ゲートを通る。具体的には着手前に存在した「守備不足の玉周辺マス」か「取り残される高価値駒」が減る。
- **漢字・演出**：「守勢」。青白い横線が守備部隊の前に入り、兵士が腰を落とす。中演出。
- **大将**：「守りを固めよ！ ここで食い止める！」
- **英語字幕**：`Strengthen the line! Hold them here!`
- **制限**：玉の近くへ駒を動かしただけでは発動しない。守備不足の判定には味方駒への守りの利きも含める。

### 08｜反撃 — COUNTERSTRIKE

- **発動条件【作戦＋解析】**：作戦「反撃狙い」の有効化後、直前まで受けていた具体的な脅威を解消し、同じ着手で相手への有効な取り・王手・玉周辺への圧力を新たに作る。安全ゲートを通る。
- **漢字・演出**：「反撃」。守備側の墨線が跳ね返り、攻撃部隊へ火花がつながる。中演出。
- **大将**：「待っていたぞ。今度はこちらの番だ！」
- **英語字幕**：`We were waiting. Now it is our turn!`
- **制限**：直前の脅威を記録し、対応関係を確認する。単に相手の駒を取り返す全ての手を対象にしない。

## 4. 好手・戦術・部隊の活躍：09〜18

### 09｜両取り — FORK

- **発動条件【確定＋解析】**：着手した1駒が、新たに相手の異なる2駒以上へ取りの脅威を作る。歩だけの組合せは除き、攻撃駒のピンや即時の取り返しを考慮する。安全ゲートを通り、相手の最善応手後にも一方への取りが有効な候補であることを解析で確認。
- **漢字・演出**：「両取り」を斜めに二筆。攻撃元から二つの対象まで短い光を分岐。中演出。
- **大将**：「二つに一つだ。選んでみよ！」
- **英語字幕**：`Two targets. Make your choice!`
- **制限**：盤面の利きが二つあるだけの段階では候補止まり。王手飛車取りなら10を優先する。

### 10｜王手飛車 — ROYAL FORK

- **発動条件【確定＋解析】**：自分の着手で相手玉を王手にし、同時に同じ攻撃駒が相手の飛車または竜を狙う。相手の合法応手を確認し、玉を守る一手で攻撃駒を安全に取る等の簡単な解消がなく、飛車取りが成立することを解析で確認。安全ゲート必須。
- **漢字・演出**：「王手飛車」。玉へ細い雷、飛車へ墨の斬線。低音の後に金属音を一発。中演出。
- **大将**：「王を守るか、飛車を救うか！」
- **英語字幕**：`Save your king—or save your rook!`
- **制限**：王手表示は即時に出すが、この称賛演出は解析完了時だけ。「飛車の獲得確定」とまでは表示しない。

### 11｜両王手 — DOUBLE CHECK

- **発動条件【確定】**：自分の着手後、相手玉に王手をかける駒が2枚以上ある。各攻撃元をルール判定から抽出する。
- **漢字・演出**：「両王手」。二方向の斬線が本陣直前で交差し、太鼓を二打。中演出。
- **大将**：「二方から迫れ！ 王を動かせ！」
- **英語字幕**：`Strike from both sides! Force the king to move!`
- **制限**：通常の王手・開き王手より優先。自動的に「詰み」や「勝利」扱いにはしない。

### 12｜開眼 — DISCOVERED CHECK

- **発動条件【確定】**：着手した駒が射線上から移動し、その後方にいた飛車・角・香、または成った飛車・角による新しい王手が成立する。着手前は当該駒から王手がかかっていない。
- **漢字・演出**：「開眼」。前衛が道を開け、後方部隊の射線に光が一瞬走る。中演出。
- **大将**：「道は開いた！ 奥の一撃を受けよ！」
- **英語字幕**：`The path is clear! Feel the strike behind it!`
- **制限**：「開眼」は演出名。戦況ログでは正式な内容として「開き王手」と記す。両王手なら11を優先する。

### 13｜串刺し — SKEWER

- **発動条件【確定＋解析】**：一直線の攻撃で相手玉に王手をかけ、その奥に相手の飛車・角・成駒がいる。相手の王手回避後、その駒を狙う射線が実際に通り、安全に取れる見込みを確認する。発動は原則として応手後。
- **漢字・演出**：「串刺し」。敵玉が動いた後の射線に鋭い一本の筆跡。中演出。
- **大将**：「退けば、その奥をいただく！」
- **英語字幕**：`Step aside, and what lies behind is ours!`
- **制限**：着手時に後続の駒が存在するだけでは称賛しない。合駒や攻撃元の捕獲で射線が消えた場合は破棄する。

### 14｜封殺 — PIN

- **発動条件【確定＋解析】**：自分の長距離駒・相手の玉以外の駒・相手玉が一直線に並び、中間の相手駒が玉をさらす移動をできない状態が新たに生まれる。少なくとも一つの幾何学的な移動先が自玉王手で非合法になったことを確認し、安全ゲートを通る。
- **漢字・演出**：「封殺」。対象部隊の足元を細い墨輪で短く囲む。中演出。
- **大将**：「その場を離れれば、本陣が空くぞ！」
- **英語字幕**：`Leave your post, and your king is exposed!`
- **制限**：「一切動けない」とは言わない。射線に沿う移動や攻撃元の捕獲が合法な場合がある。移動禁止の追加効果も付けない。

### 15｜捨身 — SACRIFICE

- **発動条件【解析】**：自分の銀以上相当の駒を差し出す着手が良手ゲートを通り、エンジンの主な応手でその駒が取られる。その後も評価が維持・改善される、または自軍の詰み筋が継続する。実際に相手が受け取った時点で再確認する。
- **漢字・演出**：「捨身」。失う部隊の指物をアップにせず、引き継ぐ味方部隊へ光を渡す。中演出。
- **大将**：「この一手に道を託す。続け！」
- **英語字幕**：`This move opens the way. Follow through!`
- **制限**：単なる取り逃し・大駒の損失には絶対に使わない。検証できない場合は通常の捕獲演出だけにする。

### 16｜突破 — BREAKTHROUGH

- **発動条件【確定＋解析】**：歩の部隊が相手の駒を取りながら成り、自分のと金が新たに敵陣へ成立する。安全ゲートを通る。
- **漢字・演出**：「突破」。足軽の槍が上がり、土煙から金の指物が立つ。中演出。
- **大将**：「よくぞ抜いた！ 足軽の意地を見せよ！」
- **英語字幕**：`You broke through! Show them an ashigaru's resolve!`
- **制限**：敵陣へ歩を進めただけでは発動しない。全兵種共通の成り表現より優先する。

### 17｜昇龍 — DRAGON ASCENDANT

- **発動条件【確定】**：飛車が今回の確定着手で竜へ成る。
- **漢字・演出**：「昇龍」。既存の飛行高度を壊さない短い上昇感、翼に金色の縁、龍の咆哮を短く重ねる。中演出。
- **大将**：「天を駆けよ！ 竜よ、戦場を制せ！」
- **英語字幕**：`Take the skies! Dragon, command the battlefield!`
- **制限**：駒IDごとに成る瞬間だけ。負け詰み等の明確な悪化が判明した場合は音声を省き、小さな成り表示にする。

### 18｜援軍 — REINFORCEMENTS

- **発動条件【確定】**：持ち駒の打ちが合法手として確定する。
- **漢字・演出**：「援軍」を画面端に小さく表示。指物が地面に立ち、部隊が短い土煙から整列する。小演出。
- **大将**：「援軍、到着！ 配置につけ！」
- **英語字幕**：`Reinforcements! Take your positions!`
- **制限**：通常は文字と効果音だけ。音声は各陣営の最初の打ち、または重要な打ちに限定。両取り・救援等が成立したらそちらを優先する。

## 5. 戦局への反応・大将の掛け声：19〜27

### 19｜王手 — CHECK

- **発動条件【確定】**：確定着手後に相手玉が王手。実際の王手元と玉を特定する。
- **漢字・演出**：「王手」。玉の札の周囲に短い朱線、文字は盤面の端。小演出。
- **大将**：攻撃側「王手だ！」／防御側の低頻度差分「慌てるな、王を守れ！」
- **英語字幕**：`Check!`／`Stay calm. Protect the king!`
- **制限**：両軍の声を同時再生しない。連続王手では音声を省略し、詰みなら29へ置き換える。

### 20｜急襲 — SUDDEN ASSAULT

- **発動条件【解析】**：相手の確定着手で、自玉周辺を攻撃する相手の有効な攻撃元が2枚以上増え、`E(自軍)`が着手前後の同条件解析で200cp以上低下。王手でなくても成立する。
- **漢字・演出**：「急襲」。守備側の本陣付近に短い墨の飛沫。中演出。
- **大将**：「まずい、敵が迫る！ 防衛せよ！」
- **英語字幕**：`They are closing in! Defend the stronghold!`
- **制限**：人間対AIでは標準でAI陣営の声に限定。人間側への助言になる演出は「戦術ガイドON」または観戦時に使う。

### 21｜死守 — STAND FIRM

- **発動条件【確定＋解析】**：自玉が王手の局面から、自分の確定着手で王手を解消し、玉を移動させずに本陣を維持する。安全ゲートを通る。
- **漢字・演出**：「死守」。受けた部隊が武器を構え、衝撃が地面へ散る。中演出。
- **大将**：「よく止めた！ まだ崩れはせぬ！」
- **英語字幕**：`Well held! We stand unbroken!`
- **制限**：悪手の合駒で詰みを早めただけなら発動しない。普通の王手回避は通常表示に留める。

### 22｜防衛 — DEFEND THE KING

- **発動条件【解析】**：対象側が手番を迎え、比較可能な複数候補の中に「負け詰みを防ぐ候補」と「負け詰みになる候補」があり、守りを誤ると危険な状態を確認する。
- **漢字・演出**：「防衛」。本陣の幟が強く揺れ、太鼓を低く一打。中演出。
- **大将**：「本陣が危うい！ 全軍、防衛せよ！」
- **英語字幕**：`The stronghold is in danger! Defend the king!`
- **制限**：未着手の受けの正解は示さない。標準ではAI陣営の反応・AI同士の観戦向け。人間側は戦術ガイドON時だけ。

### 23｜救援 — TIMELY RELIEF

- **発動条件【確定＋解析】**：持ち駒の打ちで王手を解消する、または解析済みの自玉への詰めろを消す。安全ゲートを通り、その打ちが脅威解消の原因であることを確認する。
- **漢字・演出**：「救援」。援軍の土煙と同時に本陣の危険表示が薄れる。中演出。
- **大将**：「間に合ったか！ 本陣を支えよ！」
- **英語字幕**：`Just in time! Secure the stronghold!`
- **制限**：18・21より優先。詰めろを消したか証明できない場合は、王手回避の打ちだけを対象にする。

### 24｜反攻 — TURN THE TIDE

- **発動条件【確定＋解析】**：直前まで王手を受けていた側が、王手を解消すると同時に相手へ王手をかける。安全ゲートを通る。作戦設定には依存しない。
- **漢字・演出**：「反攻」。本陣へ向かっていた光が反転して敵陣へ走る。中演出。
- **大将**：「受けるだけと思うたか！ 押し返せ！」
- **英語字幕**：`Did you think we would only defend? Push back!`
- **制限**：08との違いは、実際に王手を返したという盤面条件。08・19・21と重なった場合はこちらへ統合する。

### 25｜好機 — SEIZE THE MOMENT

- **発動条件【解析】**：相手の確定着手が同じ開始局面の最良候補より250cp以上悪く、対象側の有利な評価が二つの連続した完了深さで一致する。既に長く大差がついている状態は除く。
- **漢字・演出**：「好機」。対象側の大将の指物に一度だけ金の光。中演出。
- **大将**：「今だ！ この隙を逃すな！」
- **英語字幕**：`Now! Do not let this chance slip away!`
- **制限**：次の最善手を教える矢印・駒の点滅は出さない。標準はAI陣営・観戦向け。人間側のガイドOFF時は、その好機を実際に活かした後の称賛へ回す。

### 26｜逆転 — REVERSAL

- **発動条件【解析】**：対象側が過去の確定局面で`E(s) ≤ -300cp`の劣勢にあり、現在`E(s) ≥ +300cp`へ移行。さらに相手の一手後も`E(s) ≥ +200cp`を維持する。各時点の評価条件を揃える。
- **漢字・演出**：「逆転」を大きく打ち付ける。陣営色の墨が画面端から返り、軍勢の鬨の声を短く入れる。大演出。
- **大将**：「流れはこちらだ！ 勝機をつかめ！」
- **英語字幕**：`The tide has turned! Seize our chance!`
- **制限**：評価の微小な揺れ・正負の往復では発動しない。各陣営1局2回まで、間隔24手以上。人間対AIの評価非表示モードでは控えめな称賛に置換できる。

### 27｜圧倒 — OVERWHELMING ADVANTAGE

- **発動条件【解析】**：対象側の評価が3つの連続した確定局面で`E(s) ≥ +1000cp`を維持し、その中に相手の着手を含む。直前はこの状態でなかった。
- **漢字・演出**：「圧倒」。軍勢の指物を一度だけ強くなびかせる。中演出。
- **大将**：「押しているぞ！ だが、最後まで気を抜くな！」
- **英語字幕**：`We have the advantage! Stay sharp to the end!`
- **制限**：勝利宣言にはしない。各陣営1局1回。音量と頻度を抑え、負けているプレイヤーを繰り返し煽らない。

## 6. 決着を印象づける演出：28〜30

### 28｜必至 — NO ESCAPE

- **発動条件【証明】**：今回の着手は王手ではなく、相手が次に選べる全ての合法応手に対し、自分に1手詰めがあることを全応手探索で確認する。相手の王手・連続王手による逃れ、先に詰ませる手、引き分け・終局を生む手があれば不成立。この厳しい部分集合から対応する。
- **漢字・演出**：「必至」。一瞬だけ音楽を引き、太い墨の輪が相手本陣を囲む。大演出。
- **大将**：「包囲は成った。決着をつけるぞ！」
- **英語字幕**：`The encirclement is complete. Finish this!`
- **制限**：通常の有利評価や単なる詰めろからは絶対に出さない。証明が間に合わなければ省略。標準は観戦・戦術ガイド向けとし、人間の解答を先取りしない。

### 29｜詰み — CHECKMATE

- **発動条件【確定】**：対局ロジックが「手番側の玉が王手」かつ「合法手が0件」と判定し、詰みで終局した。
- **漢字・演出**：「詰み」。最後の着手の到着後に盤面の動きを落ち着かせ、一筆と一度の太鼓で締める。大演出。
- **大将**：勝者「これにて、決着！」／敗者差分「……見事。ここまでだ。」
- **英語字幕**：`The battle is decided!`／`Well played. This is the end.`
- **制限**：勝者・敗者の音声は設定に応じて片方を採用。エンジンの「詰み筋あり」ではなく、実際の終局だけで発動する。

### 30｜凱歌 — VICTORY

- **発動条件【確定】**：詰み、投了、実装済みの反則負け等により、対局管理が勝者を確定した。終局理由を別フィールドで受け取る。
- **漢字・演出**：「凱歌」。勝者の幟が上がり、朱印または金印の勝利表示。29がある場合は、その表示終了後に結果画面へつなぐ。大演出。
- **大将**：「よく戦った！ 皆の力でつかんだ勝利だ！」
- **英語字幕**：`Well fought! This victory belongs to us all!`
- **制限**：1局1回。千日手等の引き分けには使わず、「引分」の結果表示へ分岐。投了では詰み演出を挟まない。敗者を嘲る台詞は使わない。

## 7. 海外向けの見せ方と音声の方針

- 主役の漢字は大きく、英語見出しは直下に短く添える。英語字幕は音声と同時に表示し、意味を補う。上記英語は演出用の初稿で、収録前に自然さと長さを確認する。
- 漢字を装飾だけにせず、対象のマス・部隊へ短い視覚的な反応を結びつける。色に加えて「先手／後手」「BLUE／RED」や陣営紋でも区別する。
- 声は短く、芯のある大将の演技。全てを絶叫にせず、攻勢は高揚、守備は緊張、好手は確信、決着は静かな重さを使い分ける。
- 先手は豪胆、後手は冷静、といった声の個性を付けてもよいが、優勢・劣勢や人間・AIに固定した善悪の役割を与えない。
- 太鼓・拍子木・刀の鞘鳴り・幟の布音を中心に、イベントの強弱を揃える。長い叫びや効果音の連打で思考を妨げない。
- 実装時の音声はオリジナル収録または適切に利用できる音源を使う。本書は音声ファイルの制作・採用を確定するものではない。
- 音声OFF、字幕ON、演出「通常／控えめ／OFF」を用意する。動きを減らすOS設定では静的な文字と字幕へ置き換え、重要なルール表示は残す。
- AIが一手を決めた後も音声の終了を待たせない。次の重要イベントが来たら短くフェードし、戦況を古い台詞で説明しない。

## 8. 解析によるネタばらしを避ける

標準は、既に実行された着手への反応を中心にする。特に人間対AIでは、人間側の「今この手がある」「次に受けないと詰む」を自動音声で教え続けない。

| モード | 標準で使うもの | 条件つきで使うもの |
| --- | --- | --- |
| 手動2人対局 | 確定した王手・成り・打ち・囲い・終局 | 未着手の好機・危機は両者が戦術ガイドをONにしたとき |
| 人間対AI | 確定した着手への演出、AI大将の作戦・反応 | 人間側への好機・危機の通知は戦術ガイドON時 |
| AI同士の観戦 | 両軍の作戦・好機・危機・好手・評価推移 | 証明済みの必至も表示可能。盤面に正解の読み筋を常時描かない |
| 棋譜リプレイ | 記録された確定イベント | 解析を加えた解説は独立したON/OFF設定 |

AI停止・再開でガイド設定を勝手に変えない。手動側になった瞬間に、その側へ向けた未着手の解析通知を取り消す。

## 9. 実装用イベントの形

```ts
type BattlePresentationEvent = {
  eventId: string;              // e.g. tactical.fork / opening.fourth_file
  gameId: string;
  positionRevision: number;
  ply: number;
  side: 0 | 1;
  sourceMoveId: string;
  evidence: 'rules' | 'pattern' | 'analysis' | 'proof';
  subjectPieceIds: string[];
  targetCells: number[];
  intensity: 'small' | 'medium' | 'large';
  priority: number;
  textKey: string;              // 漢字・英語見出しの翻訳キー
  voiceKey?: string;            // 話者・陣営に応じて実音声を解決
  subtitleKey?: string;
  trigger: 'arrival' | 'after-response' | 'result';
  expiresAfterRevision: number;
};
```

検出器・調停器・再生器を分ける。検出器は局面を読み取り、将棋の状態を書き換えない。再生器は条件の正しさを推測せず、検証済みイベントだけを表示する。

解析待ちのために対局を停止しない。対象の着手が古くなった解析結果は画面に割り込ませず、必要なら解説ログだけに残す。攻撃側と防御側が同時に叫ぶ、同じ手に「見事」と「まずい」が無関係に続く、といった競合は調停器で防ぐ。

## 10. 実装順序と確認項目

### 第1段階：誤判定しにくい見せ場

まず **17 昇龍、18 援軍、19 王手、29 詰み、30 凱歌** を実装する。漢字・英語字幕・陣営の識別・音声優先順位・演出OFFを固める。将棋ロジックだけで確定でき、体験の土台になる。

### 第2段階：戦法が形になる楽しさ

01〜05の配置テンプレートと、06〜08の作戦実行イベントを追加する。指示変更と実際の成立を区別し、両軍AIの観戦でも同じ原型が同時に叫ばないように調整する。

### 第3段階：好手と戦局の盛り上がり

09〜16、20〜28を解析対応の範囲から追加する。解析がないときは断定演出を出さず、危機・逆転の閾値は実戦と代表局面で調整する。28の必至は最後に、証明できる限定パターンから扱う。

### 各演出の受け入れ条件

- 成立例と、それに似ているが不成立の例を少なくとも1局面ずつ用意する。
- 先後反転でも同じ判定になる。手動・AIの区別で発動条件が変わらない。
- 両取りの見せかけ、ピンされた攻撃駒、合駒で防げる串刺し、悪手の捨て駒を称賛しない。
- 囲いは全テンプレート駒を確認し、崩して戻す・保存復元で連発しない。
- 詰み、詰めろ、必至、有利評価、投了、引き分けを混同しない。
- 1着手から複数イベントが出ても大文字・音声は各1件。29→30だけは一つの決着シーケンスとして扱う。
- AI指示の連打、両軍AIの高速進行、停止・再開、戻す、リセットで古い声が鳴らない。
- 字幕がマスの選択やズームを妨げず、スマホでも画面外にはみ出さない。
- 音声OFF・控えめ・動きを減らす設定でも、王手と終局の意味は伝わる。

## 11. 次に決めること

初回の試作では100案全てに音声を付けるより、足軽の突破・飛車の昇龍・両取り・王手・勝利の5場面で漢字と声の気持ちよさを確認する。声の方向性は「重厚な時代劇寄り」「勢いのあるアニメ寄り」の中間を仮の基準とし、ユーザーの好みに合わせて収録台本へ展開する。

## 12. 拡張案の読み方

31〜100にも前述の安全ゲート、先後対称、音声間隔、未着手の助言制限を適用する。以下の二〜四文字の名前は原則として本アプリの演出名であり、全てが正式な将棋用語というわけではない。

- **履歴判定**：今回の局面だけでなく、確定済みの着手・駒の所有者・成り・捕獲・イベント履歴を参照する。
- **関連手**：何手前の何の攻撃・救援に反応しているかをIDで結びつける。距離や雰囲気だけで因果関係を作らない。
- **有効な脅威**：幾何学的に利くだけでなく、ピン・取り返し・相手の合法応手を確認した脅威。証明できない戦果を断定しない。
- **駒価値の暫定尺度**：歩100・香300・桂320・銀450・金550・角800・飛1000。成駒は別表を設け、取ったときに手駒では元の駒へ戻ることも計算する。交換の良否は最終的には解析で確認する。
- **部隊の戦歴**：将棋では同種の持ち駒を個体として区別しない。捕獲と再投入をつなぐ部隊IDは演出上の設定とし、同種の持ち駒は「先に捕獲されたIDから使う」等の固定規則で割り当てる。個々の兵士の生死を意味しない。
- **演出の競合**：例えば09両取りと31桂叉は別々に連続再生せず、条件が具体的な31へ置き換える。称賛条件を満たさない場合は、元になる確定事実だけをログへ残す。

## 13. 手筋を見せ場にする：31〜45

### 31｜桂叉 — KNIGHT FORK

- **発動条件【確定＋解析】**：昇格前の桂を動かす・打つことで、二つの跳躍先に相手の銀以上相当の駒が存在し、09の有効な両取り条件を満たす。
- **漢字・演出**：「桂叉」。騎馬隊長の合図に合わせ、弓足軽が二方向へ弓を構える。中演出。
- **大将**：「その跳躍、見事！ 二方を押さえたぞ！」
- **英語字幕**：`A brilliant leap! Two targets in our sights!`
- **制限**：成桂には使わない。09・18より優先し、歩二枚を狙っただけでは発動しない。

### 32｜銀挟 — SILVER WEDGE

- **発動条件【確定＋解析】**：銀の打ちで、銀から見て左右の前斜めに敵の金が一枚ずつ存在し、09の有効な両取り条件を満たす。銀が即座に安全に取られる形は除く。
- **漢字・演出**：「銀挟」。大袖を構えた重装武者が二方へ向き直り、二本の墨線が開く。中演出。
- **大将**：「金の守りを割れ！ 重装隊、踏み込め！」
- **英語字幕**：`Split their gold defenders! Heavy troops, advance!`
- **制限**：この配置に限定した銀の両取り演出。一般の銀打ちや、金二枚の単なる近接では発動しない。

### 33｜垂歩 — LOOMING PAWN

- **発動条件【確定＋解析】**：敵陣に近い空きマスへ歩を打ち、その歩は王手をかけておらず、次の前進で成れる。実際の相手応手後にも成り込みが有効な候補として残ることを確認する。
- **漢字・演出**：「垂歩」。一人分の指物から部隊全体へ静かに光が広がる。中演出。
- **大将**：「この一歩が、後に効くぞ。」
- **英語字幕**：`This single step will make itself felt.`
- **制限**：発動は応手後。打った直後に人間へ次の成り筋を教えない。安全ゲート必須。

### 34｜歩継 — PAWN RELAY

- **発動条件【履歴＋解析】**：同じ筋で自軍の歩が相手の駒に取られ、その相手駒へ別の歩を当て、さらに実際の応手で相手駒が誘導された結果、自軍の飛車等の侵入路が開く。最初の歩の投入から6手以内に連鎖が完成する。
- **漢字・演出**：「歩継」。先に消えた指物の位置から次の指物へ、短い墨の足跡がつながる。中演出。
- **大将**：「次へつなげ！ 足軽が道を開く！」
- **英語字幕**：`Keep it moving! The ashigaru will open the way!`
- **制限**：二度歩を捨てたという事実だけでは出さない。開いた経路と有効な侵入候補を確認してから称賛する。

### 35｜底支 — FOUNDATION

- **発動条件【確定＋解析】**：自陣の最下段へ歩を打ち、その前方にいる味方の守備駒を新たに支える。相手がその守備駒を取った場合の取り返しが合法となり、直前の具体的な損失の脅威を軽減する。
- **漢字・演出**：「底支」。最下段に低い墨の土台が一瞬現れる。中演出。
- **大将**：「足元を固めよ。守りはここからだ！」
- **英語字幕**：`Secure our footing. The defense begins here!`

- **制限**：連続王手の千日手で既に終局した場合は結果表示を優先。観戦では通常の王手の叫びを置き換える。

### 95｜采配 — COMMAND ACCEPTED

- **発動条件【操作状態】**：対象側が手動からAI担当へ切り替わり、エンジン初期化が成功した後、現在の有効な依頼で最初の思考を開始する。
- **漢字・演出**：「采配」をAI操作欄に小さく表示。盤面中央の決め文字は出さない。小演出。
- **大将**：「采配、承った。軍は預かるぞ！」
- **英語字幕**：`Command accepted. I will lead our forces!`
- **制限**：戦法発動とは別。停止→再開の連打では60秒に一回まで。初期化失敗や相手の手番での待機中には成功台詞を出さない。

### 96｜返還 — YOUR COMMAND

- **発動条件【操作状態】**：対象側のAIを停止し、未確定の思考依頼が無効化され、その側を手動で操作できる状態へ移る。確定済み着手の演出中なら、終了後に適用。
- **漢字・演出**：「返還」を操作欄の小表示へ。指揮を示す小さな印がAI表示から手動表示へ移る。小演出。
- **大将**：「ここからは、そなたの采配だ。」
- **英語字幕**：`From here, the command is yours.`
- **制限**：実際の操作可能状態と一致させる。相手の手番なら文字を「手動へ切替済み」に留め、今すぐ着手できると誤解させない。

### 97｜軍令 — ORDERS RECEIVED

- **発動条件【操作状態】**：AI担当側への作戦変更が受理され、古い依頼が無効になり、新しい作戦で有効な思考が始まる。最終的に採用された変更だけが対象。
- **漢字・演出**：「軍令」を操作欄へ小さく表示。小演出。
- **大将**：攻勢「攻めに転ずる。承知した！」／守備「守りを優先する。承知した！」／反撃「機をうかがう。任せよ！」／おまかせ「局面を見て決める。任せよ！」
- **英語字幕**：`We take the offensive. Understood!`／`Defense comes first. Understood!`／`We will watch for our moment. Leave it to me!`／`I will judge the position. Leave it to me!`
- **制限**：これは指示受領の返答であり、06〜08の実行演出ではない。変更の連打は最後の一件にまとめ、全体の音声クールダウンを守る。

### 98｜称賛 — A WORTHY MOVE

- **発動条件【履歴＋解析】**：相手側が15捨身・77因縁決着・88連環のいずれかを成立させ、その対局で当該相手への特別な敬意の台詞をまだ出していない。
- **漢字・演出**：「称賛」を小さく表示。敗けを断定せず、受けた側の大将の声だけを採用する。小演出。
- **大将**：「敵ながら、見事。だが、まだ終わらぬぞ！」
- **英語字幕**：`A worthy move. But this battle is not over!`
- **制限**：同じ着手の攻撃側称賛音声と二重再生しない。どちらを採用するか事前の優先規則で決め、詰みなら省略する。

### 99｜見届けよ — WATCH THE FINISH

- **発動条件【解析＋履歴】**：AI担当側が指す確定着手について、直前の解析で自軍の正の詰み評価が二つの完了深さにわたって一致し、着手後にもその側の詰み筋が確認される。まだ実際の詰みではない。
- **漢字・演出**：「見届けよ」を小さく表示。大将の幟を一度だけ強くなびかせる。小演出。
- **大将**：「最後まで見届けよ。ここから仕上げる！」
- **英語字幕**：`Watch closely. We will see this through!`
- **制限**：AI同士の観戦専用を初期値とする。人間の手番や評価非表示の対局には出さない。「詰み確定」の結果表示は29まで待つ。

### 100｜好敵手 — A WORTHY RIVAL

- **発動条件【履歴＋確定】**：対局が通常の詰み・投了・引き分けで終了し、両軍がそれぞれ異なる2種類以上の解析確認済みの好手イベントを成立させている。
- **漢字・演出**：「好敵手」を結果画面の副題にする。両軍の幟を静かに並べる。大演出の差分。
- **大将**：「よき相手であった。また、盤上で会おうぞ。」
- **英語字幕**：`You were a worthy rival. May we meet on the board again.`
- **制限**：勝利音声へ追加して長くせず、30の台詞差分または引き分け用の締めに採用。反則負け・エラー中断には使わない。

## 19. 戦歴を扱うための追加データ

次は実装時の追加案。盤面のルール状態へ戦功やバフを混ぜず、別の演出用履歴として保持する。

```ts
type UnitChronicle = {
  unitId: string;
  originalSide: 0 | 1;
  ownerSide: 0 | 1;
  ownerEpoch: number;           // 所有者変更ごとに増加
  basePieceType: string;
  firstCaptureMoveId?: string;
  captureMoveIds: string[];
  promotionMoveIds: string[];
  defenseEventIds: string[];
  rescueLinks: { allyId: string; threatId: string; moveId: string }[];
  rivalryLinks: { opponentId: string; encounterMoveIds: string[] }[];
  ownershipChanges: { moveId: string; from: 0 | 1; to: 0 | 1 }[];
  appearedEventIds: string[];
};
```

- 保存形式が古く部隊IDがない場合は、復元できる棋譜の開始局面から固定規則で再構築する。再構築できない戦歴は「なし」として扱い、架空の過去を補わない。
- 同種の持ち駒のID割当ては、同じ棋譜から必ず同じ結果になるようにする。復元前後で帰参した部隊が変わらないことを確認する。
- 戻す操作では、対象手以降の戦功・救援・因縁・所有者変更を巻き戻す。音声の既再生記録は別に持ち、戻す→指すで同じ台詞を連打できないようにする。
- AIの読み筋は将来の出来事の履歴にはしない。実際に確定した相手の応手が予想と違えば、誘引・捨身・連環の候補を再評価する。
- `操作状態`イベントは盤面のリビジョンに加え、担当・指示のリビジョンにも結びつける。古い「承知した」が現在の指示に対して鳴らないようにする。
- 昔の画面へカメラを戻して解説しない。履歴を表す線は現在の盤面上で邪魔になるなら省き、現在の対象部隊の指物と字幕だけで表現する。

## 20. シナリオをつなぐ演出例

### A：足軽が主役になる一局

1. 62 初陣撃：最初の捕獲を歩部隊Aが担当。
2. 16 突破：Aが捕獲しながら成る。
3. 85 大器：Aが成駒でさらに大きな戦果を得る。
4. 60 歩兵決着：最後にAの着手で詰みになる。

全て実際の棋譜が条件を満たした場合のみ成立する。筋書きのためにAIの手を変えたり、足軽を特別に強化したりしない。

### B：守備隊が戦いを返す

1. 20 急襲：本陣に危険が迫る。
2. 50 忠勇：旗本Bが王手の駒を取って守る。
3. 55 守護：後の別の攻撃もBが防ぐ。
4. 83 守兵反撃：Bが敵陣で有効な捕獲を達成する。

大将の台詞は、最初の「防衛せよ！」から「そなたを信じる！」へ変化する。

### C：帰ってきた部隊

1. 自軍部隊Cが捕獲され、敵に打たれる。
2. Cを自軍が取り戻し、打ち直すと56 帰参。
3. Cが戦果を挙げて57 雪辱。
4. 後に54 精鋭の条件を満たせば、再起した部隊として結果の見どころに残る。

将棋の持ち駒の扱いを、指物を継ぐ軍勢の物語へ翻訳する。

### D：大将同士が相手を認める

1. 敵の部隊Dが活躍を重ね、自軍大将が92 警戒。
2. 別の場面で敵の連環が決まり、自軍大将が98 称賛。
3. その後、自軍も好手を重ね、条件が揃って終局時に100 好敵手。

強がりや挑発一辺倒にせず、相手の好手を認めることで戦いの格を上げる。

## 21. 今回の追加分で特に先に試したいもの

- **46 下剋上**：足軽が大駒を取った瞬間。兵種の見た目と意味が直結する。
- **55 守護**：同じ旗本が王を二度守る。大将が部隊を覚えている感覚を作る。
- **56 帰参 → 57 雪辱**：持ち駒という将棋独特の仕組みを物語として伝える。
- **76 因縁 → 77 因縁決着**：同じ部隊同士の攻防を、観戦中の注目対象にする。
- **78 返礼**：仲間を助ける関係が一局の中でできる。
- **90 起死回生**：実際の大逆転勝利にだけ使う、希少な結果演出。
- **95〜97 指揮の返答**：AI開始・停止・作戦変更が、大将に指示している感触になる。

100案は「全部を頻繁に鳴らす」ための数ではなく、成立した一局に合う言葉を選べるための引き出しとする。音声の差分はこの条件群を土台に、平静・高揚・窮地の3調子、先手・後手の2話者へ展開できる。ただし未収録の音声数を実装済みの演出数には数えない。
