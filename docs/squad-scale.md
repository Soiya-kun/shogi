# 部隊化・広域フィールドの実装

更新日：2026-09-06

一駒を一部隊とし、人間の大きさを基準に戦場を拡大する計画を実装した。対局状態は従来の81マスと持ち駒のまま扱い、人数は描画上の表現とする。

## 部隊と縮尺

| 駒 | 部隊 | 人数 | 隊形 |
| --- | --- | ---: | --- |
| 歩 | 足軽隊 | 12 | 4列×3段の密集隊形 |
| 香 | 長槍足軽隊 | 10 | 5列×2段の横隊 |
| 桂 | 弓足軽隊 | 6 | 先頭の騎馬武者1人＋後続の弓足軽5人（2・3人の二段） |
| 銀 | 重装武者隊 | 8 | 4列×2段の重装二列横隊 |
| 金 | 旗本隊 | 9 | 3列×3段の方陣 |
| 飛 | 竜武者隊 | 8騎 | 高度をずらした3・2・3騎の飛行隊形 |
| 角 | 陰陽師隊 | 6 | 陰陽師1人＋護衛侍5人 |
| 王 | 本陣 | 8 | 大将1人＋旗本7人 |

飛車はドラゴンに槍を持つ騎手が乗る竜武者隊。角、翼膜、尾、鞍、手綱を備える。地上約3.5mを基準に中列だけ1.3m高く配置し、待機中も羽ばたき・上下動・尾の動きが続く。移動中も飛行を維持し、地面の影と旗をマスの目印にする。空中のドラゴン本体からも所属部隊を選択できる。成ると騎手とドラゴンの頭部の金装飾を追加する。

兵士全体は戦国時代を思わせる和風ファンタジーで統一。歩は陣笠・胴・草摺・槍・背中の指物を備えた足軽、香は長槍足軽。金は兜と前立、槍、指物のある旗本、王は陣羽織と軍配を持つ大将。角は烏帽子と白い狩衣、紙垂の付いた杖を持つ陰陽師を護衛侍5人で囲む。部隊旗は独自の三つ丸紋を入れた縦長の幟とした。特定の武将・家紋の再現ではない。

桂馬は馬に乗った武者1人と、地上を歩く弓足軽5人で構成。隊長は兜・前立・陣羽織・太刀・和風の馬具を備える。弓足軽は陣笠と軽装の胴、上下非対称の和弓、弦、矢筒、矢を持つ。PC・スマホとも1人＋5人を維持する。

銀は8人の重装武者隊。通常兵より大きい胴・五段の大袖・草摺・兜・鍬形・面頬・籠手・脛当てを持ち、長い太刀を装備する。専用の原型と遠景モデルを使う。角の護衛は通常装備の侍として区別する。成りでは全兵種に金の胸元・肩の装飾が加わる。

飛車の乗り手も兜・面頬・和甲冑と槍の竜武者へ変更した。ドラゴンの形状、飛行高度と隊形、翼・尾の動きは維持する。

地上部隊はマスの幅と奥行きを広く使う配置とした。兵士の中心点間で横7.3〜8.4m、奥行5.8〜7.8mが目安。歩兵は横8.1m×奥行6.8m、長槍は8.4m×5.8m、桂馬の弓足軽隊は7.6m×7.0m。護衛の輪も広げ、隊形ごとの特徴を維持する。装備を含む静止モデルが12m四方に収まることを確認している。

初期配置は40部隊・392人。スマホ幅では各部隊を6人、合計240人で表現する。省略時も配置順の両端を含め、マスの広さを使った隊列にする。省略表示でも部隊の構成人数、移動能力、持ち駒数は変わらない。UIに部隊名・人数・隊形を表示する。

- 1マス12m、対局範囲は108×108m。従来の14.4m四方から一辺7.5倍。
- 周辺の地形は480×480m。対局範囲の外に木、岩、石積みの遺構を配置。
- 兵士原型はWebで1.25倍に統一し、人間に近い身長で配置。隊長の馬や槍、旗はそれぞれの寸法を維持。
- 部隊ごとに陣営色の旗と駒名・人数の表示を置く。接近時は表示札の画面上の大きさを抑える。

## 地形と質感

Blenderの連続した地面メッシュから、地上部隊の足元、飛行部隊の基準高度、線・ハイライトの高さを求める。各マス中央の高低差は約4.86m。対局範囲は緩い丘陵で、周囲の丘はさらに高い。

Poly Havenの草・乾いた土・岩の1Kテクスチャ9枚を同梱。各素材の色、法線、粗さを小道・高さ・位置に応じて混ぜる。草は縮尺と回転の異なる画像を重ね、繰り返しを弱める。枝と葉で構成した木、草、小石、岩、石積み、日光と距離による霞を加えた。

素材はCC0。配布元とライセンスは [sources.json](../dist/assets/textures/sources.json)、[Poly Haven license](https://polyhaven.com/license) に記録する。モデルと地形形状はオリジナル。地面材質の混合はWeb側で行うため、Blenderのプレビューでは頂点カラーの地面が表示される。

## 動きと操作

- 移動方向へ隊列を向け、後続に遅れをつけて進み、到着時に整列する。陣営の正面へ向きを戻す際は最短方向に回転する。
- 捕獲は短い攻撃と相手部隊の後退・退場。持ち駒は部隊単位で再投入する。
- 成ると金の旗、装飾、駒名、発光を更新。人数を減らすHP・損耗の仕組みは設けない。
- 「全景」で軍勢全体、「部隊に寄る」で選択部隊（未選択時は操作カーソル位置）へ接近。
- ドラッグ回転、ホイール、2本指の拡大縮小、俯瞰、駒名切替、矢印とEnterの操作。
- ホイールはカーソル直下の地面・兵士・飛行中のドラゴンの位置を基準に拡大縮小し、その地点をカーソルの下に保つ。選択中の部隊に依存せず、縮小時も盤面中央へ戻さない。ピンチは2本指の中央を基準にし、中央位置の移動にも追従する。空や地形の外側では現在の注視点を通る画面に平行な平面を基準にする。
- ズーム範囲は8〜240m（縦画面は距離を1.5倍に補正）。距離に比例したホイールの移動量で、接近中は細かく調整できる。地表から最低0.8mのカメラ高を保ち、地面へ入るズームは手前で止める。「部隊に寄る」は選択部隊へ48mまで接近し、「全景」は185m・中央の視点へ戻す。
- 兵士同士の隙間を含むマス全体を選択範囲とする。選択後に近づいても移動先を選べる。
- 動きを減らすOS設定では歩行・旗の揺れ・羽ばたきを止め、ドラゴンの空中姿勢を保ったまま、移動演出を即時完了する。

## 描画と編集

| ファイル | 担当 |
| --- | --- |
| `dist/formations.mjs` | 部隊の人数・配置・スマホ省略表示 |
| `dist/squad-renderer.js` | GLBの部位を結合、インスタンス描画、距離による詳細度変更 |
| `dist/terrain-material.js` | 草・土・岩の材質混合 |
| `dist/battlefield.js` | 地形の読込、部隊移動、カメラ、旗、選択と操作 |
| `scripts/landscape.py` | Blender地形・植生の再生成 |
| `scripts/build_assets.py`、`scripts/samurai.py` | 全10種類の和風原型、軽量モデル、編集元の再生成 |
| `scripts/update_samurai.py` | 地形を保持して全兵士とLOD・プレビューサンプルを更新 |
| `scripts/archer.py`、`scripts/update_knight.py` | 和風弓兵の互換入口、桂馬の騎馬隊長・弓兵のみを更新 |
| `scripts/heavy_knight.py`、`scripts/update_silver.py` | 銀の重装武者原型とLOD・編集元を更新 |
| `scripts/export_assets.py` | 手編集を保持してGLBを書き出し、軽量モデルを更新 |

同じモデル・陣営・昇格状態をまとめて描画する。遠景ではBlenderで簡略化したモデルを使い、接近時は元の装備と可動部位を表示する。切替距離に幅を設けて境界でのちらつきを防ぐ。全景でもドラゴンの翼・尾を別々に動かす。飛行部隊が存在する間は羽ばたきと高度を継続更新する。スマホは人数、描画解像度、影解像度を抑える。

地形と兵士のGLBは合計約23.32MiB、テクスチャは約6.73MiB。初回アート素材の合計は約30.05MiB。現段階の検証上限は合計34MiB、描画500回未満、PC110万三角形未満、スマホ全景60万三角形未満とする。
