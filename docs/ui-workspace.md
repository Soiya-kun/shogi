# 戦場と操作パネル

2026-09-06の方針変更：右パネルは細くせず、用途を切り替えるか閉じて省略できる構成にする。

- **戦況**：手番・現在の状態・選択部隊・待機部隊・戻す／最初から。
- **指揮**：独立したヘッダーボタンから両軍のAI開始／停止・戦法・作戦を開く。パネルを閉じてもAIは継続する。
- **履歴**：棋譜と戦局演出の記録。現在の戦況と分離する。
- **歯車**：言語・駒名・AI速度・戦闘演出・音声・字幕などを専用モーダルに集約。

戦況・指揮・履歴は同じ幅の右パネルを切り替える。同じボタン、×、Escで閉じる。PCでは閉じた分だけ戦場が広がる。スマホは最初から閉じ、必要なパネルだけを手前に開く。モーダルには閉じるボタンとEsc操作がある。

全景・部隊に寄る・視点回転・俯瞰の画面ボタンは削除。左ドラッグの水平移動、右ドラッグの回転、カーソル中心のホイール拡大、タッチ選択・ピンチは維持する。演出は戦場左下に表示する。

既存のカメラ検証はdebugモードのカメラ操作口を利用し、UIナビゲーションは共通のテスト補助へ移した。通常画面に非表示の旧ボタンを残してはいない。

検証：単体48件、アセット検証が成功。ブラウザ39ケースのうち通し実行で37件成功し、旧ナビゲーションに依存した2件は手順修正後の再実行で成功。新UIの専用ケースも再実行し、パネル開閉・AI継続・設定・日英切替・履歴・スマホの盤面収まりを確認。PCの戦況・指揮・設定とスマホの画面を目視確認した。
