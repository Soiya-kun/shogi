# ヤンキー衣装 v2 の反映

2026-09-06、`assets/blender/yankee/clothing-v2` の保存済み8個のBlender原本を `scripts/export_yankee_clothing_snapshot.py` でGLBへ書き出した。原本は上書きしない。出典ファイルとSHA-256を配信用 `clothing-sources.json` に記録する。

全8兵種の衣服を更新。低い襟、片側のボタン、胸ポケット、肩に収まる袖、つながったボンタンと腰・膝・裾の皺、長丈のベント、ローファー、役職刺繍を反映。顔・髪・バイクは新版原本に含まれる造形をそのまま使用する。

Web用には密度の高い衣服メッシュを軽量化し、8体合計39,314,280 bytesから22,208,368 bytesに削減。細かい刺繍・顔・靴を一律に簡略化しない。材質別のインスタンス描画に変更し、布・革・金具の色、粗さ、金属度を保持する。Blenderのプロシージャルな織りのバンプは未ベイクであり、Cyclesの見本画像との完全一致はしない。

1マス1人、約1.78mの人物、3mマス、バイクの寸法を維持する。部位別の新しい戦闘クリップは含まないため、既存の接近・応戦・退場を使用する。成りは既存の駒名・ルールで表示。街v3のGLBはハッシュ不変。

検証：全8GLBの実読み込み、単一人物ルート、寸法、接地、カメラ・ライトの混入なし、材質差の検証1件が成功。PC／スマホのブラウザ4件成功。舞台選択、保存復元、捕獲、成り、待機駒、AI、舞台切替、ヤンキー演出・日英字幕・取消を確認。アセット検証成功。

最終データを近景で目視確認。40人・119人物材質バッチ、全体229 draw calls、約666万三角形、当端末の短時間サンプルで平均描画17.6ms。三角形数は旧版より増えており、低性能端末向けの専用LODは今後の改善対象。
