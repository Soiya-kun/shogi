# 駒取り・部隊戦闘アニメーションの設計方針

作成日：2026-09-06

状態：2026-09-06に全兵種の戦闘演出と非同期制御を実装。本文は採用設計を保持し、実装値・検証結果は[戦闘演出の実装記録](combat-implementation.md)へ記載する。

関連：[AI・戦法・作戦指示](ai-strategy-design.md)、[戦局演出・大将の掛け声](battle-presentation-scripts.md)。

## 1. 必須要件：指し手を演出で待たせない

> **移動・攻撃・命中・撃破・進駐のアニメーションは、駒を指す処理と非同期に再生する。演出の完了を次の着手・AI思考の開始条件にしない。先手・後手のAIが対局している場合、戦闘が続いている間にも次々と指し手が確定し、別の部隊が移動・戦闘を始められること。**

将棋の着手自体は手番順に一手ずつ合法性を検証し、局面・持ち駒・成り・棋譜・終局を確定する。その確定直後に次の手番へ進み、AIなら最新の確定局面から思考を開始する。人間の操作も演出中という理由では制限しない。通常の手番・合法手・成り選択等の制約は維持する。

非同期にするのは表示であり、未確定局面に対する先読みや、先後の同時着手を意味しない。AIの思考時間や観戦速度の設定は演出の長さから独立させる。

例：先手の足軽が敵を取って槍を突いている間に、後手のAIが次の手を確定して弓部隊が移動する。先手のAIも次の思考を始め、最初の戦闘が終わる前にさらに着手できる。

## 2. 採用する戦闘の流れ

一駒を一部隊として、**攻撃 → 命中 → 敵部隊が倒れる → 勝った部隊が進駐する**流れを見せる。これは一件の演出内の順序であり、対局全体の待ち時間にはしない。

| 駒・部隊 | 攻撃演出 | 見せたい特徴 |
| --- | --- | --- |
| 歩：足軽 | 前列が槍を構えて踏み込み、一斉に突く。後列も少し遅れて続く | 集団で押し込む勢い |
| 香：長槍足軽 | 長槍を水平に下ろし、隊列を保って突撃する | 直線的な突破力 |
| 桂：騎馬武者＋弓足軽 | 騎馬隊長が太刀を掲げて合図し、弓足軽が一斉射撃。着弾後に隊長が先導して進む | 指揮と弓の連携 |
| 銀：重装武者 | 大きく踏み込み、太刀を両手で振り下ろす。敵がよろめいて倒れる | 鎧と一撃の重さ |
| 金：旗本 | 前列が敵を牽制し、左右の兵がタイミングを合わせて槍を突く | 熟練した連携 |
| 角：陰陽師と護衛侍 | 陰陽師が札を放ち、敵の足元に術式が現れる。敵が怯んだところへ護衛侍が斬り込む | 術と剣の合わせ技 |
| 飛：騎馬武者／成り後の龍武者 | 通常は馬の部隊が槍を構えて突撃する。成り後は東洋の龍が高度を下げて炎を吐き、乗り手が槍を突き出す。撃破後は再び浮上する | 騎馬の突破力と、成り後の空から攻める迫力 |
| 王・玉：大将と旗本 | 大将が軍配を振り、護衛が前へ出て攻撃。大将は後方で指揮する | 本陣らしい威厳 |

敵側は前列から順に姿勢を崩し、旗が傾いて、最後に部隊が消える。流血を使わず、土煙・火花・衝撃音で見せる。撃破は部隊の敗走・戦闘不能を含む表現とし、持ち駒として再投入できる将棋の扱いを維持する。王・玉の攻撃は合法な駒取りに対応し、敵玉の捕獲を新たなルールにしない。

通常の尺は追加の希望を反映し、戦闘部分を約3秒、接近・進駐を各約0.6秒とする。合計約4.2秒。敵側も武器を構えて応戦し、最後は着手した側が勝って進駐する。AIは標準で約3秒に1手とし、戦闘の完了は待たない。現在のカメラを保ち、拡大すると武器の動きまで見えるようにする。強制的なカメラ切替や時間停止を前提にしない。

成り駒の専用モーションは後続の調整項目とし、初期は元の部隊の攻撃を用い、成りの装飾を維持する。

## 3. 連続着手と表示の競合

- **別の部隊・場所の戦闘は並行再生する。** 全演出を一本の待ち行列にして、次の着手や移動を待たせない。
- **同じ部隊が演出中に再び動く場合は最新の着手を優先する。** 古い攻撃・進駐を短縮して新しい移動へつなぐ。古い演出の完了処理で部隊を以前のマスへ戻さない。
- **取り返しも待たせない。** 攻撃中の部隊が次の手で取られたら、その部隊の旧演出を打ち切り、最新の捕獲に対応する表示へ移る。既に終わった出来事として古い土煙等を短く残すことはできる。
- **被撃破部隊は演出用の一時表示として残す。** 論理局面では捕獲と同時に盤上から除き、持ち駒へ反映する。倒れている表示は選択・合法手・AIの探索に参加させない。
- **取った直後の打ちにも対応する。** 倒れている旧陣営の表示と、持ち駒から打たれた新陣営の部隊を別の表示世代として扱い、旧演出の終了が新しい部隊を消さないようにする。
- **操作とルール表示は最新局面を参照する。** 駒の旗の陣営・駒名、選択先・合法手・王手表示・棋譜・持ち駒を最新状態へ更新し、演出上の残像を現在の駒として選ばせない。旗の位置は旗手の兵士に追従させ、移動先へ先行させない。
- **演出が追いつかない場合は表示を短縮する。** 同時再生数・残存時間に上限を設け、古い残像・粒子・音を省略する。演出待ちによる指し手の遅延や、無制限の蓄積を避ける。上限値は実測して決める。

## 4. 実装時の責務と注意点

対局管理は着手の確定と次の手番の開始を担当し、描画側は確定済みイベントを受け取って再生する。移動や戦闘の完了Promise、`animationend`、タイマーを次の手番への遷移条件にしない。演出の失敗・省略・中断でも確定済みの指し手は変わらない。

演出イベントには対局ID、局面更新番号、イベントID、対象部隊IDと表示世代、着手時点の位置・陣営・駒種・成り状態を保持する。再生中に変化する現在の駒オブジェクトだけを参照して、過去の攻撃対象や陣営を書き換えない。

古い局面のAI回答は破棄する一方、既に確定した着手に由来する戦闘は、別の場所の着手が進んだだけでは一律に消さない。同じ部隊・表示への競合、巻き戻し・リセット・復元による無効化を区別する。

戻す・リセット・復元では関連する演出、残像、遅延音声、完了処理を無効化し、復元先の局面へ表示を同期する。終局判定とAI停止も演出完了を待たずに行い、最後の戦闘を残す場合も表示だけ継続する。

戦局の筆文字・掛け声にも同じ非同期方針を適用する。音声の頻度制限や候補の優先順位は別途守り、再生待ちが着手を止めないようにする。

## 5. 確認すること

1. AI同士で演出時間より短い着手間隔を設定し、最初の戦闘終了前に後続の着手が確定して別部隊が動く。
2. 手動操作でも戦闘中に次の合法手を入力でき、操作対象と持ち駒が最新局面に一致する。
3. 同じ部隊の再移動、連続した取り返し、捕獲直後の打ちで、部隊の巻き戻り・重複・誤消去が起きない。
4. 演出中の戻す・リセット・復元・終局で、古い完了処理や音声が新しい局面へ干渉しない。
5. 多数の連続捕獲でも残像やイベントが蓄積せず、演出をOFFにした場合と将棋の確定結果が一致する。

制作は足軽の槍突きと重装武者の斬撃を基準に進め、まず非同期で連続着手できる構造を確認してから、各兵種の演出を広げる。
