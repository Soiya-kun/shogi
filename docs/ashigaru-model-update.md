# 足軽モデルの更新

2026-09-06、保存済み `assets/blender/ashigaru-reference/ashigaru-reference.blend` の詳細シーンとLODシーンを、原本を変更せず `scripts/export_ashigaru_snapshot.py` で書き出した。

配信用スナップショットは `dist/assets/ashigaru/detail.glb`（627,828 bytes）と `lod.glb`（140,264 bytes）。サイズ・SHA-256を同ディレクトリのmanifestへ記録。制作中のBlender原本と共用army.glbは上書きしない。

`ashigaru-assets.js` が戦国舞台の足軽原型だけを差し替える。制作寸法に0.8倍、既存描画の1.25倍がかかり、人の高さ約1.78mを維持する。原点は足元、腕・脚ピボットと陣営用TeamClothを保持。既存の成り装飾を引き継ぐ。

足軽は部位と材質ごとにインスタンス化し、漆・鉄・肌・布の粗さと金属度を保持する。他兵種の既存バッチ方式は維持。45描画単位未満の近距離は詳細版、遠距離はLOD。旗持ちだけは遠距離でも部位を分離できる詳細原型を使い、右手の槍全体を除去して手の中心へ旗を付ける。人数と隊列は変えない。

検証：単体51件、旗持ちのブラウザ2件成功。先後の歩の移動・割込み・戻す、スマホ、騎馬・龍の旗の回帰を確認。アセット検証成功。PCの40部隊392人の近景を目視確認し、443 draw calls／約196万三角形／平均描画12.4msを観測した（当端末の短時間サンプルであり全環境のFPS保証ではない）。

音声や他兵種の制作モデル、ヤンキー舞台は今回の差し替え対象に含めない。次回も保存済みの原本から上記スクリプトで書き出し、manifestと検証結果を更新する。
