# 戦局演出の実装状況・検証記録

更新日：2026-09-06

[100案の設計書](battle-presentation-scripts.md)に対し、共通基盤と44案を実装。最初に指定された17・18・19・29・30・95〜97、戦法01〜08、解析で確認する好手、部隊IDを使う戦歴の順に実装した。残る56案は条件判定器を登録していない。台詞だけを雰囲気で再生する経路はない。音声は未収録。

## 共通基盤

- Matchが合法手・持ち駒・成り・終局を確定してから、読み取り専用の検出層へ渡す。3D戦闘・字幕・解析・音声は次のAI思考や着手を待たせない。
- gameId、局面revision、操作revision、演出番号、陣営、部隊IDで重複と古い結果を除外。次の着手では旧局面の待機演出・解析を取り消すが、表示済みの戦局字幕は開始から5秒まで維持する。新しい演出は置き換えて表示。AI停止・指示変更、戻す、リセット、設定変更では字幕・待機タイマー・音声・解析を即座に取り消す。
- 表示時間は強度を問わず5秒。29「詰み」の5秒表示後、100msを挟んで30「凱歌」を5秒表示する。表示時間はAIの着手間隔に影響しない。
- 成立イベントは全て最大48件のログへ記録。主表示は1着手1件、終局＞防衛・王手＞好手＞戦法＞通常。29→30だけ専用連続表示、60は結果副題。遅い解析は、既に主表示があればログだけ。
- 漢字、日本語台詞、英語見出し・字幕、先後名とBLUE/RED、現在の対象マスへの短い印。カメラは操作しない。UIはpointer-events:none。視点ボタンとは重ならない位置に表示。
- 通常／控えめ／OFF、字幕、英語、音声、音量、解析による好手演出を端末内保存。OSの動きを減らす設定では静止表示。OFFでも既存の王手・終局表示は残る。
- 音声は既定OFF、単一HTMLAudio、全体8秒・同陣営4自軍手の間隔。中演出は同じ番号・側で12自軍手の間隔。終局音声は各番号・側・局で1回。新しい局では自軍手数の間隔を初期化する。
- AI停止は戦局字幕・音声を取り消す。既に確定した別部隊の3D戦闘は従来どおり完走する。96の返還は戦闘完了と実際の手動操作可能状態を確認する。

## 解析と戦歴の成立範囲

AIの既存探索を再利用し、人間の着手には必要時だけ別Workerで短時間解析する。手動の静的配信では、解析のためだけに隔離ヘッダー準備のリロードを起こさない。解析が使えない場合も確定演出は動く。

比較条件は同じ開始局面・同じ完了深さ・欠けのないMultiPV・確定値。最良候補から100cp以内で、より深い完了探索の負け詰みがない場合だけ安全ゲートを通す。mateとcpは換算しない。有限探索なので絶対的な安全証明ではない。やねうら王のGenerateAllLegalMovesを有効にし、不成の省略でMultiPVの必要順位が欠けないようにした。

未来の正解や危機を人間に教える演出はまだ実装していないため、戦術ガイド用スイッチも追加していない。必至・捨身・逆転・因縁などは下表の不足する根拠が実装されるまで無効。

部隊IDは検証可能な棋譜の起点から決定的に復元。持ち駒の同兵種は捕獲順FIFO。所有者変更ごとに期間を進め、過去の所有者の戦功を新所有者の連続功績にしない。棋譜が復元できない場合は現局面から履歴を始め、原所属や過去の戦果を作らない。解析証跡は追加のpresentation欄に保存し、戻すでは以降の証跡・捕獲・昇格・戦功を除去する。ルール上の能力や勝敗には影響しない。

## 検証結果

- 単体：新規20テスト群が成功。先後反転、欠けた囲い、元の飛車でない例、解析なし・101cp悪化・bound・未完了深さ・古い依頼、ピンされた攻撃、解消できる王手飛車を確認。
- 戦歴：実際の合法手19手で原所属の歩が敵軍経由で帰参し雪辱すること、FIFO、同部隊の安全な捕獲3回、独立した防衛2回、8手静止の伏兵を確認。複合演出81/83/84/85/89は局面＋履歴fixtureで成立と近似不成立を確認。全種を自然なAI対局で観測したという意味ではない。
- ブラウザ：新規7ケースで基本演出、29→30、95〜97、3秒間隔、保存復元・戻す・リセット、スマホ・低動作・OFF、実物WASMによる人間着手の証跡、実際のHTMLAudio再生と取消を確認。
- 全体回帰：単体47件、Chromeのブラウザ32件成功（32件の通し実行7.3分）。既存の全兵種戦闘・取り返し・即時の打ち・保存復元・スマホ・カメラ・ズーム・右ドラッグを維持。AI着手間隔は2,990／2,999ms。実物WASMの人間着手解析は完了深さ7・最良候補との差0cpで突破／下剋上を検出した。
- 音声の本収録・演技・音量バランスは未検証。検証用WAVはテスト時のHTTP応答だけに用い、製品の音声には収録していない。
