# 日本語・英語

歯車の設定内にあるLanguageで日本語／Englishを選ぶ。既定は日本語。設定は`aether-language`へ保存し、対局・AI・棋譜をリセットせずに切り替える。

- 操作案内、部隊情報、AI設定と状態、確認モーダルを選択言語で表示する。
- 演出の大きな漢字タイトル（王手・詰み・昇龍など）と駒の漢字表記は日本語を主軸として維持する。英語の短いタイトル副題は別設定で表示できる。
- 台詞・説明の字幕は選択した一言語のみ。日本語と英語の説明文を同時に積み重ねない。表示中の演出も切り替え、元の表示期限は延長しない。
- 棋譜の将棋表記は共通表記を維持する。外部のルール参照やライセンス文書は翻訳対象外。
- 音声は未収録。今後、音声マニフェストの各イベント・陣営に`ja`／`en`の音声パスを指定できる。既存の単一パスは日本語用として扱い、英語音声がない場合は英語字幕だけを表示する。

翻訳辞書とUIの原文保持は`dist/i18n.js`、演出字幕と音声選択は`dist/presentation-view.js`。原文から表示を作り直すため、言語を往復しても操作ボタンや設定値を壊さない。
