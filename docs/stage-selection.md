# 開始時の舞台選択

街アセット更新：ヤンキー舞台は現在[黒金一番街 v3](yankee-city-v3.md)。電飾ゲートと繁華街・路面材質を更新した。以下の初回取り込み時の記録にある「暁の交差点」は旧版名。

ヤンキー専用のタイトル・口調・戦闘モーションの方針は[ヤンキー将棋：戦局演出設計](yankee-presentation-design.md)を参照。語彙調査の出典を含む。44イベントの専用タイトル・日英字幕・ログは実装済み。専用音声素材・兵種別モーションは今後の工程。

初回起動で舞台を選択し、以後は選んだ舞台と対局を復元する。「戦況 → 最初から」でも舞台を選び直せる。別の舞台へ切り替える場合は新しい対局として開始し、旧AI・演出を破棄してページを再読み込みする。初回選択画面でも日本語／英語を変更できる。

| 舞台 | フィールド | 駒の表示 |
| --- | --- | --- |
| 戦国将棋 | 風渡る草原、108m四方の対局域 | 既存の侍部隊、392人（スマホ240人） |
| ヤンキー将棋 | 暁の交差点、27m四方の対局域 | 昭和〜平成初期の暴走族8兵種、1マス1人。バイクも運転者1人 |

ヤンキー版は別タスク「足軽モデルを制作」で制作された初版の交差点・全8兵種をアプリ用にコピーしたもの。制作中のBlender原本は更新しない。`dist/assets/stages/yankee`はWeb配信用のスナップショット。交差点の静的形状は`export_stage_snapshot.py`で人物の配置見本・確認用グリッドを除いて書き出した。将棋のグリッドと現在の40駒は実際の局面から描画する。

内部座標では4描画単位＝1mとして既存の将棋座標と共用する。画面には3mマス・27mの対局域として表示。待機駒、成り、捕獲、再投入、AI操作、戻す、表示切替は共通の将棋状態に従う。ヤンキーの戦闘は接近・体の応戦・退場を行い、侍用の矢・札・龍の炎は表示しない。

**美術の実装範囲**：街と人物の基本形を組み込み済み。別タスクで進む汚れ・生活感の追加、衣装の陣営差分、成り専用モデル、専用台詞・戦闘モーションはこのスナップショットには含めない。成りは駒名と将棋の移動能力で判別する。街のプロシージャル材質はGLBで表現可能な範囲の基本材質を使用する。

舞台IDは`aether-stage`に保存し、対局保存にもstageを記録。未知のIDは戦国版を既定値とする。読み込み失敗時には再読み込みと舞台の選び直しを案内する。
